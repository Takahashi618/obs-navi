# OBSナビ

English: [README.en.md](README.en.md)

OBSナビは、スクリーンリーダー（PC-Talker・NVDA）で OBS Studio を操作するための Windows 用の道具です。

OBS Studio の画面には、スクリーンリーダーで読めない・操作しにくいところが多くあります。OBSナビは、読み上げで扱いやすい自分の画面から OBS を操作します。操作には、OBS Studio に標準で入っている WebSocket という仕組みを使います。OBS は起動したままにしておき、その横で OBSナビを使います。OBS 本体で操作した変化（配信の開始やシーンの切り替えなど）も、OBSナビが読み上げます。

すべての操作はキーボードだけで行えます。

現在はテスト版です。

## AI を使って作ったソフトです

OBSナビのソースコードと文書は、AI（Anthropic の Claude）を使って書きました。

何を作るか、どう動くべきか、読み上げで使いやすいかは、作者が決めています。作者自身がスクリーンリーダーで使い、確かめながら直してきました。あわせて、自動テスト（tests フォルダ）で動作を確かめています。

## できること

- 配信と録画の開始・停止、録画の一時停止、チャプター（目印）、リプレイの保存、仮想カメラ
- 状態の読み上げ（配信中か、録画中か、今のシーン）
- シーンの切り替え・作成・設定・削除
- ソースの表示・非表示、作成・設定・削除、重なり順の変更
- ゲーム切り替え（ゲームの映像と音を、まとめて別のゲームへ向ける）、映像切り替え、BGM の再生
- 音声のミュート、音量（デシベルで読み上げ）、レベル（今の音の大きさ）の読み上げ、モニタリング（自分の耳に返すか）
- 録画の音声トラックの割り当て（ゲームの音・スクリーンリーダーの声・マイクを別のトラックに分けて録る）
- 音声フィルター（ノイズ抑制など）の追加・設定・削除
- カメラが動いているかの確認と、有効・無効の切り替え
- スクリーンリーダーの声を配信に乗せる・乗せないの切り替え
- 配信中・録画中の、無音と音割れの警告。録画中の空き容量の警告
- ゲーム中でも効くキー（配信・録画の開始と停止など）
- 日本語と英語の表示（Windows の表示言語に合わせて自動で選び、「ツール」メニューの「表示の言語 (Language)」で変えられます）

## できないこと

- OBS のインストールと、配信先（Twitch・YouTube など）の設定。配信キーの入力などは OBS 本体で行います
- YouTube の配信枠を作ること。OBS 本体の「配信の管理」で行います
- 映像フィルター（クロマキーなど）の追加。すでにある映像フィルターの確認・オン・オフ・削除はできます
- OBS 本体のシーンの並び順を変えること。OBSナビの中の並び順は変えられます
- モニタリングの聞こえる先（どのヘッドホンで聞くか）の設定。OBS 本体の設定で行います

## 動作環境

- Windows 10 または Windows 11（64ビット）
- OBS Studio 28 以降（WebSocket が標準で入っている版）。古い版では、チャプターのように使えない機能があるので、できるだけ新しい版を使ってください
- スクリーンリーダーは PC-Talker または NVDA
- インストールは要りません。管理者の権限も要りません

## 使い方

使い方の全体は、マニュアル（[docs/manual.html](docs/manual.html)。英語版は [docs/manual.en.html](docs/manual.en.html)）にあります。GitHub の画面では HTML のまま表示されるので、ダウンロードしてブラウザーで開いてください。見出しで移動しながら読めるように、章ごとに見出しを付けてあります。

最初に必要なのは、OBS の WebSocket サーバーを有効にすることだけです。

1. OBS Studio を起動します。
2. Alt+T で「ツール」メニューを開き、「WebSocket サーバー設定」を選んで Enter を押します。
3. 「WebSocketサーバーを有効にする」のチェックボックスをオンにします。
4. 「認証を有効にする」がオンになっていることを確かめます。
5. 「サーバーパスワード」が空なら、「パスワードを生成」を押します。
6. 「OK」を押して閉じます。

パスワードを書き写す必要はありません。OBSナビは、OBS の設定ファイルからパスワードとポート番号を自分で読み取ります。認証をオフにすると、OBSナビは接続しません。

OBS の設定画面が読み上げで扱いにくいときは、設定ファイルを直接書き換える方法もあります。マニュアルの 3.1 節に手順があります。

## ソースから動かす

確かめた環境は、Windows 11 と Python 3.14（64ビット）です。コマンドはこのフォルダで実行します。

1. 部品を入れます。

   ```
   python -m pip install wxPython==4.2.5 obsws-python==1.8.0 websocket-client==1.9.0 accessible_output2==0.17
   ```

2. 起動します。

   ```
   python -X utf8 app.py
   ```

3. テストを走らせます（OBS は要りません）。

   ```
   python -X utf8 tests\run_tests.py
   ```

   英語の表示に日本語が残っていないかは、別に確かめます（画面を英語で作って調べます）。

   ```
   python -X utf8 tests\en_probe.py
   ```

## 実行ファイルの作り方

1. PyInstaller を入れます。

   ```
   python -m pip install pyinstaller==6.20.0
   ```

2. OBSナビを終了してから、次を実行します。起動したままだと、読み上げ用の DLL が欠けたまま作られることがあります。

   ```
   python -X utf8 -m PyInstaller --noconfirm obs_navi.spec
   ```

3. dist\OBSNavi\OBSNavi.exe ができます。

配布用の zip は、`python -X utf8 tools\build_release.py` で作ります。

## フォルダの中身

- app.py は、起動の入口です
- version.py は、版の番号です
- speech.py は、スクリーンリーダーへの読み上げです
- core フォルダは、OBS との通信と、画面に依存しない処理です。キーの定義は core\keymap.py に、表示の言語の決め方は core\i18n.py にあります
- ui フォルダは、画面（wxPython）です
- tests フォルダは、テストです
- tools フォルダは、文書の生成と検査、配布パッケージの作成です
- docs フォルダは、マニュアルとテストのお願いの元の HTML です（manual.en.html と tester.en.html は英語版）
- obs_navi.spec は、実行ファイルを作る設定（PyInstaller）です
