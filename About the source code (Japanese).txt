■ フォルダの中身

・README.md は、OBSナビの紹介と、ソースからの動かし方です。README.en.md はその英語版です。
・About the source code (Japanese).txt はこのファイルで、About the source code (English).txt はその英語版です。
・app.py は、起動の入口です。
・version.py は、版の番号です。
・speech.py は、スクリーンリーダーへの読み上げです。
・core フォルダは、OBS との通信と、画面に依存しない処理です。キーの定義は core\keymap.py に、表示の言語の決め方は core\i18n.py にあります。
・ui フォルダは、画面（wxPython）です。
・tests フォルダは、テストです。
・tools フォルダは、文書の生成と検査、配布パッケージの作成です。
・docs フォルダは、マニュアルとテストのお願いの元の HTML です（manual.en.html と tester.en.html は英語版）。
・obs_navi.spec は、実行ファイルを作る設定（PyInstaller）です。


■ 動かし方

作者が確かめた環境は Windows 11 と Python 3.14.5（64ビット）です。
使っている部品と、確かめた版は次のとおりです。

・wxPython 4.2.5
・obsws-python 1.8.0
・websocket-client 1.9.0
・accessible_output2 0.17
・PyInstaller 6.20.0（実行ファイルを作るときだけ）

1. 部品を入れます。
   python -m pip install wxPython==4.2.5 obsws-python==1.8.0 websocket-client==1.9.0 accessible_output2==0.17
2. 起動します。
   python -X utf8 app.py
3. テストを走らせます（OBS は要りません）。
   python -X utf8 tests\run_tests.py
   英語の表示を確かめるときは、python -X utf8 tests\en_probe.py も走らせます。


■ 実行ファイルの作り方

1. PyInstaller を入れます。
   python -m pip install pyinstaller==6.20.0
2. OBSナビを終了してから、次を実行します（起動したままだと、読み上げ用の DLL が欠けたまま作られることがあります）。
   python -X utf8 -m PyInstaller --noconfirm obs_navi.spec
3. dist\OBSNavi\OBSNavi.exe ができます。

配布用の zip は、python -X utf8 tools\build_release.py で作ります。


以上です。
