1. はじめに

OBS Studio の画面には、スクリーンリーダーで読めない・操作しにくいところが多くあります。OBSナビは、読み上げで扱いやすい自分の画面から、OBS を操作します。

操作には、OBS Studio に標準で入っている WebSocket という仕組みを使います。OBS は起動したままにしておき、その横で OBSナビを使います。OBS 本体で操作した変化（配信の開始やシーンの切り替えなど）も、OBSナビが読み上げます。

できること

  • 配信と録画の開始・停止、録画の一時停止、チャプター（目印）、リプレイの保存、仮想カメラ
  • 状態の読み上げ（配信中か、録画中か、今のシーン）
  • シーンの切り替え・作成・設定・削除
  • ソースの表示・非表示、作成・設定・削除、重なり順の変更
  • ゲーム切り替え（ゲームの映像と音を、まとめて別のゲームへ向ける）、映像切り替え、BGM の再生
  • 音声のミュート、音量（デシベルで読み上げ）、レベル（今の音の大きさ）の読み上げ、モニタリング（自分の耳に返すか）
  • 音声フィルター（ノイズ抑制など）の追加・設定・削除
  • カメラが動いているかの確認と、有効・無効の切り替え
  • スクリーンリーダーの声を配信に乗せる・乗せないの切り替え
  • 配信中・録画中の、無音と音割れの警告。録画中の空き容量の警告
  • ゲーム中でも効くキー
  • 日本語と英語の表示（Windows の表示言語に合わせて自動で選び、メニューから変えられます）

できないこと

  • OBS のインストールと、配信先（Twitch・YouTube など）の設定。配信キーの入力などは OBS 本体で行います
  • YouTube の配信枠を作ること。OBS 本体の「配信の管理」で行います
  • 映像フィルター（クロマキーなど）の追加。すでにある映像フィルターの確認・オン・オフ・削除はできます
  • OBS 本体のシーンの並び順を変えること。OBSナビの中の並び順は変えられます
  • モニタリングの聞こえる先（どのヘッドホンで聞くか）の設定。OBS 本体の設定で行います

AI を使って作ったこと

OBSナビのプログラムとこの文書は、AI（Anthropic の Claude）を使って書きました。何を作るか、どう動くべきか、読み上げで使いやすいかは、作者が決めています。作者自身がスクリーンリーダーで使い、確かめながら直してきました。あわせて、自動のテストで動作を確かめています。

「ヘルプ」メニューの「OBSナビについて」でも、このことを読み上げます。

表示の言語

OBSナビは、画面と読み上げを日本語か英語で出します。最初は Windows の表示言語に合わせ、日本語なら日本語、それ以外なら英語にします。

変えるときは、「ツール」メニューの「表示の言語 (Language)」を選びます。この項目は、どちらの言語になっていても見つけられるよう、日本語と英語を併記してあります。「自動」「日本語」「English」から選ぶと、今すぐ再起動するかを聞きます。「はい」で、選んだ言語で起動し直します。「いいえ」なら、次に起動したときから変わります。

OBS で付けた名前（シーンやソースの名前）は訳しません。OBSナビが最初に用意するソースの名前（「ゲームキャプチャ」「BGM音楽」など）は、設定ファイルを初めて作ったときの言語で決まります。

英語のマニュアルは、同じフォルダの「Manual (English).html」と「Manual (English).txt」です。

2. 動作環境

  • Windows 10 または Windows 11（64ビット）。開発と確認は Windows 11 で行っています
  • OBS Studio 28 以降（WebSocket が標準で入っている版）。開発と確認は OBS Studio 32.2 で行っています。古い版では、チャプターのように使えない機能があるので、できるだけ新しい版を使ってください
  • スクリーンリーダーは PC-Talker または NVDA
  • インストールは要りません。管理者の権限も要りません

3. 準備と起動

3.1 OBS の WebSocket サーバーを有効にする

OBSナビは、OBS の WebSocket サーバーにつないで操作します。最初の1回だけ、OBS で次の設定をします。

  1. OBS Studio を起動します。
  2. Alt+T で「ツール」メニューを開き、「WebSocket サーバー設定」を選んで Enter を押します。
  3. 「WebSocketサーバーを有効にする」のチェックボックスをオンにします。
  4. 「認証を有効にする」がオンになっていることを確かめます。オフならオンにします。
  5. 「サーバーパスワード」が空なら、「パスワードを生成」を押します。
  6. 「OK」を押して閉じます。

パスワードを書き写す必要はありません。OBSナビは、OBS の設定ファイルからパスワードとポート番号を自分で読み取ります。なお、認証をオフにすると OBSナビは接続しません（パスワードの無い接続はしない作りです）。

OBS の設定画面が読み上げで扱いにくいとき

OBS の設定ファイルを直接書き換える方法もあります。

  1. OBS を一度起動してから、終了します（最初の起動で設定ファイルが作られます）。
  2. メモ帳で次のファイルを開きます。%APPDATA%\obs-studio\plugin_config\obs-websocket\config.json
  3. "server_enabled": false の false を true に書き換えて、上書き保存します。書き換えるのはこの1か所だけです。
  4. OBS を起動します。

3.2 OBSナビを置く

  1. zip ファイルを選んでアプリケーションキーを押し、「すべて展開」で展開します。
  2. 展開したフォルダを、「ドキュメント」など自分が書き込めるフォルダに置きます。

配布物のファイル名とフォルダ名は、文字化けしないようにすべて英字にしてあります。本体は OBSNavi.exe、このマニュアルは「Manual (Japanese)」です。日本語の書類は名前の最後に (Japanese)、英語の書類は (English) が付いています。

「Program Files」の中などには置かないでください。OBSナビは、自分と同じフォルダに設定ファイル（obs_navi_config.json）を作ります。書き込めない場所では設定が保存されません。

展開する前に zip ファイルの「プロパティ」（Alt+Enter）を開き、「全般」タブの「許可する」のチェックボックスをオンにしておくと、次の節の Windows の警告が出なくなります。

3.3 起動する

  1. OBS Studio を起動しておきます。
  2. OBSナビのフォルダにある OBSNavi.exe を起動します。
  3. 最初に「OBSナビ バージョン 0.20.1 の状態」と読みます。これが起動した OBSナビの版です。
  4. 続けて「OBSに接続しました。配信停止中、録画停止中、現在のシーン …」のように読めば準備完了です。

「Windows によって PC が保護されました」という画面が出たときは、Tab キーで「詳細情報」へ移って Enter を押し、さらに Tab キーで「実行」ボタンへ移って Enter を押します。電子署名の無いアプリなので出る画面で、この配布物に問題があるという意味ではありません。

OBS を後から起動したときは、「ツール」メニューの「OBSに再接続」を選びます。OBS を先に終了すると、「OBSが終了しました。OBSを起動してから再接続してください」と読みます。

3.4 終了する

Alt+F4 を押すか、「配信・録画」メニューの「終了」を選びます。確認の画面は出ません。

Escape キーでは終了しません。Escape は設定の画面を閉じるキーなので、画面を閉じるつもりで OBSナビまで終了しないようにしてあります。

OBSナビを終了しても、OBS や、配信・録画は止まりません。

4. 画面の構成

OBSナビの画面には欄が6つあり、Tab キーで上から順に回ります（Shift+Tab で逆に回ります）。起動したときは1つ目の状態の欄にいます。

  1. 状態（読み取り専用の欄）。名前は「OBSナビ バージョン 0.20.1 の状態」です。配信・録画の状態と今のシーン、接続できなかったときはその理由が入ります。
  2. 配信・録画（リスト、4項目）。配信を開始、配信を停止、録画を開始、録画を停止の4つです。上下矢印で選んで Enter で実行します。項目名にはキーも入っています（「配信を開始 Ctrl+S」）。
  3. シーン一覧。Enter で、選んでいるシーンに切り替えます。選ぶだけでは切り替わりません。
  4. ソース一覧。シーン一覧で選んでいるシーンの中のソースです。行は「ゲームキャプチャ 表示中」のように、名前と表示の状態を読みます。Enter で表示と非表示を切り替えます。シーン一覧で別のシーンを選べば、配信中の画面を変えずに、そのシーンの中身を確かめられます。
  5. 音声入力一覧。音を持つソースです。行は「マイク オン プラス5デシベル」「BGM ミュート中 0デシベル」のように、名前・ミュートの状態・音量を読みます。Enter でミュートを切り替え、左右キーで音量を変えます。
  6. フィルター一覧。最後に選んだソース（ソース一覧か音声入力一覧で選んだもの）のフィルターです。行は「ノイズ抑制 オン」のように読みます。Enter でオンとオフを切り替えます。

5. 基本の操作

5.1 リストと Enter

どのリストも、上下矢印で選んで Enter で実行します。同じ操作はメニューバーにもあるので、キーを覚えていなくても辿り着けます。

5.2 アプリケーションキーのメニュー

リストでアプリケーションキーを押すと、そのリストでできる操作の一覧が出ます。アプリケーションキーの無いキーボードでは Shift+F10 でも同じです。開いた直後はどの項目も選ばれていないので、下矢印を押してから選び、Enter で実行します。先頭はいつも設定です。

今は選べない項目も、消さずに残してあります（選べない項目として読み上げられます）。リストごとに出る項目は次のとおりです。

  • シーン一覧では、シーンの設定、シーンを作る、シーンを削除、シーン一覧の並び順（4項目）
  • ソース一覧では、ソースの設定、フィルターを追加、ソースを作る、ソースを削除、ソースを前に出す（重なり順）、ソースを後ろに送る（重なり順）、ソース一覧の並び順（7項目）
  • 音声入力一覧では、ソースの設定、フィルターを追加、音量を数値で入力、ソースを削除、レベル読み上げの順番、録画のトラック割り当てを読む（6項目）
  • フィルター一覧では、フィルターの設定、フィルターを追加、フィルターを削除（3項目）

5.3 メニューバー

Alt キーか F10 でメニューバーを開きます。左右矢印でメニューを、上下矢印で項目を選び、Enter で実行します。項目にキーがあれば、項目名の後ろに読み上げます。メニューは「配信・録画」「シーン」「ソース」「フィルター」「カメラ」「音声」「ツール」「ヘルプ」の8つで、操作する対象ごとに分けてあります。全部の項目は13章にあります。

5.4 設定の画面

ソース・フィルター・シーンの設定は、同じ作りの画面です。

  • 最初は「設定項目」のリストにいます。行は「項目の名前、今の値」の形です。
  • Enter で値を変えます。オンとオフの項目はその場で切り替わり、選ぶ項目は候補の一覧が、数値や文字の項目は入力欄が出ます。
  • 変えた値は、すぐに OBS に反映されます。「保存」ボタンはありません。
  • Tab でボタンへ移れます。ソースの設定には「読み直す」「OBSのプロパティ画面を開く」「閉じる」、フィルターの設定には「既定値に戻す」「読み直す」「閉じる」、シーンの設定には「読み直す」「閉じる」があります。
  • Escape で閉じます。

このアプリで変えられない項目は、「OBSのプロパティ画面を開く」で OBS 本体の画面を開いて変えます。

5.5 確認の画面

配信の開始と停止、削除などの前には「確認」の画面が出ます。ボタンは「はい」と「いいえ」で、最初は「いいえ」が選ばれています。Enter だけでは実行されないので、実行するときは Tab キーで「はい」へ移ってから Enter を押します。押し間違いで配信が始まったり、ソースが消えたりしないためです。

6. 配信と録画

6.1 開始と停止

  • 配信を開始するのは Ctrl+S、停止するのは Ctrl+Shift+S です。どちらも確認の画面が出ます。
  • 録画を開始するのは Ctrl+R、停止するのは Ctrl+Shift+R です。確認はありません。
  • 画面の「配信・録画」のリストや、「配信・録画」メニューからも選べます。

配信先（Twitch・YouTube など）と配信キーは、あらかじめ OBS 本体で設定しておきます。

始まると「配信を開始しました」「録画を開始しました」のように読みます。これは OBS からの知らせを受けて読むので、OBS 本体で操作したときも同じように読みます。すでに配信中に開始を押したときは「すでに配信中です」と読み、何もしません。

開始と停止を1つのキーにまとめていないのは、状態を取り違えて、始めるつもりで止めてしまうのを防ぐためです。

6.2 ゲーム中に使う配信・録画のキー

次の4つは、ゲームやほかのアプリを使っている間も効きます。

  • Ctrl+Alt+Shift+F6 で配信を開始（2回続けて押す）
  • Ctrl+Alt+Shift+F7 で配信を停止（2回続けて押す）
  • Ctrl+Alt+Shift+F8 で録画を開始
  • Ctrl+Alt+Shift+F9 で録画を停止

配信の2つは、確認の画面の代わりに2回押しで確かめます。1回目で「もう一度押すと配信を開始します」と読み、8秒以内にもう一度押すと実行して「配信を開始します」と読みます。途中で別のキーを押すと取り消されます。キーを押しっぱなしにしても2回とは数えません。確認の画面を出さないのは、ゲームの画面から OBSナビへ切り替わってしまわないようにするためです。

6.3 録画の一時停止

Ctrl+P（どこにいても効くキーは Ctrl+Alt+Shift+F5）で、録画の一時停止と再開を切り替えます。F5 の状態読み上げは「録画一時停止中」と言い分けます。一時停止のままにしていると、5分ごとに知らせます（間隔は設定ファイルで変えられます）。

6.4 チャプター

録画中に Ctrl+Alt+Shift+F12 を押すと、その位置にチャプター（あとで聞き直すための目印）を付けます。名前は「01 00:12:34」のように、番号と録画の中の時刻です。

チャプターを付けられるのは、録画フォーマットがハイブリッド MP4 かハイブリッド MOV のときだけです。OBS 本体の「設定」の「出力」にある「録画フォーマット」で、「Hybrid MP4 (.mp4)」か「Hybrid MOV (.mov)」を選びます（日本語表示の OBS でも、この2つは英語のまま表示されます）。変えたあとは OBS を起動し直す必要があります。

今使えるかどうかは、「配信・録画」メニューの「録画設定の確認」で分かります。「チャプターが使えます」「チャプターはOBSを再起動すると使えます」「このフォーマットではチャプターは使えません」のどれかを読みます。

6.5 録画のファイルと設定の確認

  • 録画を止めると「録画を停止しました。ファイル …」と、ファイル名を読みます。
  • 「配信・録画」メニューの「最後の録画を開く」で、エクスプローラーを開き、そのファイルを選んだ状態にします。この起動のあいだに録画していなければ、保存先のフォルダを開きます。
  • 「録画設定の確認」で、保存先・フォーマット・品質・エンコーダ・録画する音声のトラック・空き容量・チャプターの可否を読みます。読むだけで、設定は変えません。

6.6 リプレイの保存と仮想カメラ

Ctrl+Alt+F12 で、リプレイ（直前の数十秒）を保存します。保存が終わると「リプレイを保存しました。ファイル …」と読みます。

リプレイを使うには、OBS 本体の「設定」の「出力」で「リプレイバッファを有効にする」をオンにしておきます。リプレイバッファが動いていないときは、まず起動します。起動した直後は保存できないので、数十秒たってからもう一度押してください。

Ctrl+Alt+F11 で、仮想カメラ（OBS の映像をほかのアプリへ渡す機能）のオンとオフを切り替えます。

6.7 配信中・録画中の見張り

配信中か録画中のあいだは、次の3つを見張って読み上げで知らせます。

  • 無音: 音声の入力が60秒続けて無音だと、「マイク が60秒以上無音です」のように知らせます。スクリーンリーダーの声の入力は、無音が普通なので知らせません。
  • 音割れ: 音の大きさがマイナス0.5デシベル以上になると、「マイク が音割れしています」のように知らせます。
  • 空き容量（録画中だけ）: 録画先のドライブの空きが10ギガバイトを下回ると警告し、2ギガバイトを下回ると強く警告します。

どれも設定ファイルで変えられます（14章）。

6.8 状態と統計の読み上げ

F5（どこにいても効くキーは Ctrl+Alt+F5）で、配信中か、録画中か、今のシーンを読みます。配信中・録画中なら経過時間も読みます。

Ctrl+Alt+F10 で統計を読みます。CPU の使用率、フレームレート、コマ落ちの有無、空き容量です。

6.9 録画の音声トラック（音を分けて録る）

録画では、音を最大6本のトラックに分けて残せます。ゲームの音・スクリーンリーダーの声・マイクを別々のトラックにしておくと、あとで編集ソフトでそれぞれの音量を直せます。OBS 本体ではチェックの並んだ表で設定する場所ですが、OBSナビでは1行に1本ずつ並べ、Enter で入り切りします。

決めることは2つです。

  1. 録画するトラック: 「配信・録画」メニューの「録画のトラック設定」。「トラック1を録画する、オン」のような行が6本並びます。Enter で入り切りすると、「録画する音声をトラック1から4にしました。次の録画から効きます」のように読みます。
  2. ソースごとに音を出すトラック: 音声入力一覧でソースを選び、ソースの設定（アプリケーションキーのメニューの先頭）を開くと、最後に「録画のトラック1、オン」から「録画のトラック6」までが並びます。Enter で入り切りすると、「マイク をトラック4に出しました。今はトラック1と4」のように読みます。録画していないトラックへ出したときは、そのことも続けて読みます。

おすすめの割り当ては次のとおりです。トラック1は「全部入り」で、配信と同じ音になります。録画するのはトラック1から4です。「録画のトラック設定」の「おすすめの割り当てを聞く」でも読めます。

おすすめの割り当て
ソース出すトラック
ゲームや音楽の音1 と 2
スクリーンリーダーの声1 と 3
マイク1 と 4

確かめるときは、「音声」メニュー（または音声入力一覧のアプリケーションキーのメニュー）の「録画のトラック割り当てを読む」を選びます。録画するトラックと、ソースごとの出し先を読み、録画に入らないソースがあれば名前を挙げます。読むだけで、設定は変えません。

  • 録画中は、録画するトラックを変えられません。次の録画から効く設定なので、録画を止めてから変えます。
  • OBS の出力モードが「基本」で、録画品質が「配信と同じ」のときは、録画は配信と同じ1本の音になり、この設定は効きません。そのときは開いたときに読み上げで知らせます。OBS 本体の「設定」の「出力」で、出力モードを「詳細」にするか、録画品質を「配信と同じ」以外にしてください。
  • 配信に使うトラックは OBS 本体の設定のままです（初めはトラック1）。トラック1を「全部入り」にしておけば、配信の音は今までどおりです。

7. シーン

  • 切り替え: シーン一覧で選んで Enter。切り替わると「シーン …」と読みます。
  • 作る: 「シーン」メニューの「シーンを作る」で、名前を入力します。同じ名前があれば別の名前にして、そのことを読みます。作っても今のシーンは変わりません（配信中の画面は切り替わりません）。
  • 設定: 「シーンの設定」で、名前、切り替え効果（このシーンへ切り替えるときだけ使う効果）、切り替えの長さを変えられます。「このシーンにソースを追加する」で、ほかのシーンにあるソースを置けます。
  • 削除: 「シーンを削除」。確認の画面で、このシーンにしか無いソースも一緒に消えること、元に戻せないことを伝えます。最後の1つは削除できません。
  • 並び順: 「シーン一覧の並び順」で、OBSナビの一覧の並びを変えられます。OBS 本体の並びは変わりません。

シーンにソースを追加すると、コピーではなく同じソースを共有します。片方で設定を変えると、置いてあるすべてのシーンに効きます。

8. ソース

8.1 表示と非表示

ソース一覧で Enter を押すと、表示と非表示を切り替えます。

非表示にすると音も消えます

OBS では、ソースを非表示にすると、そのソースの音も配信と録画から消えます。映像だけを入れ替えたいときは、映像切り替え（8.4）か重なり順（8.6）を使ってください。

8.2 作る・設定する・削除する

「ソース」メニューの「ソースを作る」で、種類を選び、名前を入力します。作る先は、シーン一覧で選んでいるシーンです。

作るとすぐに設定の画面が開きます。ゲームキャプチャなら対象のゲーム、カメラなら使う機材のように、選ばないと映らない・鳴らない項目を先に選んでください。

作れるソースの種類です。上から、選ぶ画面に並ぶ順です。表は12行で、列は「種類」と「何のためのものか」の2つです。

種類 何のためのものか
カメラウェブカメラやキャプチャーボードの映像を取り込みます
ゲームキャプチャゲームの画面を取り込みます
ウィンドウキャプチャ選んだウィンドウの画面を取り込みます
画面キャプチャモニター全体を取り込みます
アプリの音選んだアプリの音だけを取り込みます
マイクなどの音声入力マイクやライン入力の音を取り込みます
パソコンの音スピーカーへ出ている音をまとめて取り込みます
音楽や動画のファイル手元のファイルを再生します
画像画像ファイルを画面に出します
テキスト文字を画面に出します
ブラウザウェブページを画面に出します。配信の通知などに使います
単色の背景決めた色で塗りつぶした四角を置きます

設定を変えるには、ソース一覧か音声入力一覧で選んで、アプリケーションキーのメニューの「ソースの設定」を選びます。音を持つソースでは、設定の先頭の行がモニタリングです（9.4）。

削除するには「ソースを削除」を選びます。ソースの削除は、このシーンから外すことではなく、すべてのシーンから消すことです。元に戻せません。BGM やゲーム切り替え、スクリーンリーダーの声に使っているソースなら、確認の画面でそのことも伝えます。

8.3 ゲーム切り替え

F3（どこにいても効くキーは Ctrl+Alt+F3）で、起動中のゲームのウィンドウの一覧が出ます。選んで Enter を押すと、ゲームの映像と、ゲームの音の両方をそのゲームへ向けます。

  • 映像に使うのは、既定では「ゲームキャプチャ」という名前のソースです。この名前が無ければ、ゲームキャプチャのソースの中から使います（2つ以上あれば選びます）。
  • 一緒に切り替える音は、既定では「ゲーム音」という名前の、「アプリの音」のソースです。

「ゲーム音 は対象が見つかりません」と読むとき

「ゲーム音」という名前のソースが無いときも、この文を読みます（続けて「ゲームを起動してから、もう一度 F3 で」と案内しますが、ゲームを起動しても直りません）。ゲームの音も一緒に切り替えたいときは、「アプリの音」のソースを「ゲーム音」という名前で作るか、設定ファイルの game_switch の audio_sources に、使っているソースの名前を書いてください。

どこにいても効くキーで呼んだときは、OBSナビの画面を前に出してから一覧を出します。前に出せなかったときは、Alt+Tab で OBSナビに切り替えてから F3 を押すよう案内します。

8.4 映像切り替え

Ctrl+E で、配信に出ているシーンの映像ソースのうち、どれを一番手前に出すかを選びます。キャプチャーボードの映像（信号の無い画面）がゲームの画面を覆ってしまうときに、ソースを消さずに切り替えられます。

非表示を使わないので、音には影響しません。ただし、キャプチャーボードの音は、映像が奥に回っても配信に乗り続けます。止めたいときは、音声入力一覧でミュートしてください。

8.5 BGM

Ctrl+B（どこにいても効くキーは Ctrl+Alt+F7）で、BGM の再生と一時停止を切り替えます。

  • 初めて使うときは、BGM 用のソース（既定の名前は「BGM音楽」）を今のシーンに作るか聞きます。「はい」を選ぶと、音楽ファイルを選ぶ画面が出ます。
  • OBS に「音楽や動画のファイル」のソースがすでにあれば、それを使います（2つ以上あれば選びます）。
  • 音楽ファイルが見つからないときは、選び直す画面が出ます。

BGM が自分に聞こえないときは、モニタリングを確かめてください（9.4）。

8.6 重なり順と一覧の並び順

ソース一覧で Alt+上矢印を押すと、選んでいるソースを1段手前に出し、Alt+下矢印で1段奥へ送ります。「5件中、前から2番目」のように、動いた先の位置を読みます。重なり順は映像の手前と奥の順で、OBS 本体にも反映されます。音には影響しません。

「ソース一覧の並び順」は、OBSナビの一覧の並びだけを変えます（OBS 本体は変わりません）。

並び順を変える画面では、リストで Alt+上下矢印を押すと、選んでいる行が1つずつ動きます。「上へ移動」「下へ移動」のボタンでも動かせます。「保存」で決め、「キャンセル」でやめます。

9. 音声

9.1 ミュート

音声入力一覧で Enter を押すと、ミュートを切り替えます。

ミュートは「配信・録画に乗せない」だけです。モニタリングがオンのソースは、ミュートしても自分には聞こえ続けます。逆に、モニタリングが「自分だけ聞く」のソースは、ミュートを解除しても配信には乗りません。どちらのときも、OBSナビは読み上げで一言添えます。

9.2 音量

  • 音声入力一覧で左右キーを押すと1デシベルずつ、Shift+左右キーで5デシベルずつ上げ下げします。
  • F7 で数値を入力できます。「-10」「5」「+3.5」のように書きます。全角の数字でも、「dB」を付けても受け付けます。範囲はマイナス100からプラス26デシベルです。
  • どこにいても効くキーは、Ctrl+Alt+F1 で下げる、Ctrl+Alt+F2 で上げる、Ctrl+Alt+Shift+F1 と F2 で大きく下げる・上げるです。対象は、音声入力一覧で選んでいる入力です。Ctrl+Alt+F4 で対象を次の入力へ移し、名前と音量を読みます。

音量はデシベルで読みます（「マイク プラス6デシベル」）。OBS のミキサーのつまみでは届かない、0デシベルより大きい値も扱えます。

9.3 レベルの読み上げ

F6（どこにいても効くキーは Ctrl+Alt+F6）で、各入力の今の音の大きさを順に読みます。読むのは直近3秒の最大の値なので、話の息継ぎの瞬間に押しても「無音」とは読みません。ミュート中の入力は「ミュート中」と読みます。

読む順番は、「音声」メニューの「レベル読み上げの順番」で変えられます。順番に載せていない入力は、後ろに名前順で続きます。「ミュート中のソースを読み上げない」をオンにすると、ミュート中の入力を飛ばします。

9.4 モニタリング（自分の耳に返すか）

OBS の既定では、ソースの音は配信と録画には乗りますが、自分には聞こえません。BGM を入れたのに聞こえない、の原因はたいていこれです。

ソースの設定の画面の先頭の行で変えます。選べるのは次の3つです。

  • オフ、配信に乗るが自分には聞こえない（OBS の既定）
  • 自分だけ聞く、配信には乗らない
  • 自分も聞く、配信にも乗る

聞こえる先（どのスピーカーやヘッドホンか）は、OBS 本体の「設定」の「音声」にある「モニタリングデバイス」で決めます。

9.5 スクリーンリーダーの声を配信に乗せる

既定では、PC-Talker の声と NVDA の声を、それぞれ別に配信へ乗せたり外したりできます。

  • PC-Talker の声は F9（どこにいても効くキーは Ctrl+Alt+F9）
  • NVDA の声は F8（どこにいても効くキーは Ctrl+Alt+F8）

押すたびに、配信に乗せる・乗せないが切り替わります（その入力のミュートを切り替えています）。

初めて押したときは、取り込むための入力を作るか聞きます。「はい」を選ぶと、今のシーンに入力を作ります。作った入力は最初はミュート（配信に乗らない）です。もう一度押すと配信に乗ります。スクリーンリーダーの声は、うっかり配信に流れないよう、明示して乗せる作りにしてあります。

PC-Talker の場合

PC-Talker の声だけを取り込みます（「アプリの音」の仕組み）。入力を作るときに PC-Talker が起動している必要があります。

NVDA の場合

NVDA は、取り込みに必要なウィンドウを持たないため、仮想の音声ケーブル VB-CABLE（無料）を通して取り込みます。準備が要るので、使う方だけ次の手順を行ってください。

  1. VB-CABLE をインストールします。入手先は https://vb-audio.com/Cable/ です。インストールすると、録音デバイスに「CABLE Output」が増えます。インストーラーの画面は読み上げられないことがあります。そのときは、管理者として開いたコマンドプロンプトで、展開したフォルダへ移ってから VBCABLE_Setup_x64.exe -i -h と実行すると、画面を使わずにインストールできます（作者の環境で確かめた方法です）。
  2. Windows のサウンドの設定（Windows キー+R で mmsys.cpl と入力）の「録音」タブで、「CABLE Output」のプロパティを開きます。「聴く」タブの「このデバイスを聴く」をオンにし、再生に使うデバイスを普段のスピーカーかヘッドホンにします。これをしないと、NVDA の声が自分に聞こえなくなります。
  3. NVDA の設定の「オーディオ」で、出力デバイスを「CABLE Input」にします。
  4. OBSナビで F8 を押し、入力を作ります。

元に戻すときは、NVDA の出力デバイスを元に戻します。

スクリーンリーダーの声の入力は、無音が普通なので、無音の警告の対象から外してあります。名前・キー・取り込み方は設定ファイルの sr_sources で変えられます。

10. フィルター

フィルター一覧には、最後に選んだソース（ソース一覧か音声入力一覧で選んだもの）のフィルターが出ます。

  • オン・オフ: フィルター一覧で Enter。「ノイズ抑制 を有効にしました」のように読みます。
  • 追加: ソース一覧か音声入力一覧でソースを選び、アプリケーションキーのメニューの「フィルターを追加」を選びます（「フィルター」メニューからも選べます）。種類の一覧は、名前と何のためのものかを読みます。最初は「ノイズ抑制」が選ばれています。
  • 設定: 「フィルターの設定」で、数値や方式を変えます。「既定値に戻す」で最初の値に戻せます。名前と並び順は変わりません。
  • 削除: 「フィルターを削除」。確認の画面が出ます。

追加できる音声フィルターの種類です。上から、選ぶ画面に並ぶ順です。表は9行で、列は「種類」と「何のためのものか」の2つです。

種類 何のためのものか
ノイズ抑制エアコンやパソコンのファンなど、ずっと鳴っている音を減らします
ノイズゲート小さい音のときは音を止めます。話していない間の物音を消せます
コンプレッサー大きい音を抑えて音量を揃えます。声が聞き取りやすくなります
リミッター決めた大きさを超えないようにします。音割れを防げます
ゲイン音量を上げ下げします。マイクが小さいときに使います
イコライザー低音・中音・高音の量を変えます
エキスパンダー小さい音をさらに小さくします。ノイズゲートよりゆるやかです
アップワードコンプレッサー小さい音を持ち上げます。ささやき声を聞こえやすくします
位相反転音の波を反転します。2本のマイクが打ち消し合うときに使います

映像フィルターは追加できません。音を持たないソースで「フィルターを追加」を選ぶと、その理由を読みます。

11. カメラ

  • カメラの確認: 「カメラ」メニューの「カメラの確認」で、カメラ（映像キャプチャデバイス）のソースごとに、機材の名前、動いているか、映像が来ているか、表示しているかを読みます。パソコンにつないであるのに OBS で使っていない機材も知らせます。
  • 有効・無効: 「カメラの有効・無効」（どこにいても効くキーは Ctrl+Alt+Shift+F11）で、カメラを止めたり動かしたりします。カメラのソースが2つ以上あるときは選びます。切り替えてから2.5秒ほどで実際の状態を確かめて読み、止められなかったときは「止められませんでした。カメラはまだ動いています」と警告します。

「仮想カメラの切り替え」（Ctrl+Alt+F11）とは別のものです。こちらは本物のカメラ、あちらは OBS の映像をほかのアプリへ渡す仮想カメラです。

14. 設定ファイル

設定は、OBSNavi.exe と同じフォルダの obs_navi_config.json に入っています。初めて起動したときに作られます。並び順や BGM のソース名など、OBSナビの操作で変えた内容もここに保存されます。

  • 書き換えるときは、OBSナビを終了してから、メモ帳などで開きます。起動中に書き換えると、OBSナビが上書きすることがあります。
  • 形が壊れて読めないときは、OBSナビは最初の設定で起動し、そのことを読み上げます。このときは設定を変えても保存されません（壊れたファイルを上書きしないためです）。
  • 最初の状態に戻したいときは、OBSナビを終了してから、このファイルを削除します。次に起動したときに作り直されます。
  • OBS への接続のパスワードは、このファイルには入れません（OBS の設定ファイルから読みます）。

設定ファイルの主な項目です。項目の名前のうち、点で区切ってあるものは「点の前の項目の中にある」という意味です（例えば record.disk_warn_mb は record の中の disk_warn_mb）。表は24行で、列は「項目」、「既定値」、「意味」の3つです。

項目 既定値 意味
language"auto"表示と読み上げの言語。"auto" は PC の表示言語に合わせ（日本語なら日本語、それ以外は英語）、"ja" は日本語、"en" は英語。「ツール」メニューの「表示の言語」でも選べます。次に起動したときから効きます
auto_passwordtruetrue なら、接続のポートとパスワードを OBS の設定ファイルから読みます。ふつうは変えません

global_hotkey_modifier"Ctrl+Alt"どこにいても効くキーの修飾キー。Ctrl・Alt・Shift・Win を + でつないで書きます。強い段はこれに1つ足したもの（Alt が入っていなければ Alt、入っていれば Shift）になります
sr_sourcesNVDA音声（キー F8）、PC-Talker音声（キー F9）スクリーンリーダーの声を配信に乗せる入力。名前・方式・キー（F1 から F12）を持ちます

15. 困ったとき

「OBSに接続できません。OBSが起動しているか確認してください」と読む
OBS が起動しているか、WebSocket サーバーが有効か（3.1）を確かめます。OBS を後から起動したときは、「ツール」メニューの「OBSに再接続」を選びます。
「WebSocketのパスワードが取得できません」と読む
OBS の「WebSocket サーバー設定」で「認証を有効にする」をオンにし、サーバーパスワードがあることを確かめて「OK」で閉じます。そのあと「OBSに再接続」を選びます。
「OBSとの認証に失敗しました」と読む
OBS でパスワードを作り直した直後などに起きます。OBS の「WebSocket サーバー設定」を「OK」で閉じてから、「OBSに再接続」を選びます。
何も読み上げない
スクリーンリーダーが起動しているかを確かめます。OBSナビは、起動しているスクリーンリーダーを自分で選んで読み上げます。
起動したときに「次のグローバルホットキーは登録できませんでした」と読む
どこにいても効くキーの一部を、ほかのアプリが使っています。そのキーは効きませんが、ほかのキーやメニューは使えます。設定ファイルの global_hotkey_modifier を変えると、まとめて別の修飾キーにできます。
設定が保存されない
書き込めないフォルダに置いている可能性があります。「ドキュメント」などへ移してください（3.2）。
画面と読み上げが英語になっている（日本語にしたい）
「ツール」メニュー（Alt+T）の「表示の言語 (Language)」で「日本語」を選びます（1章の「表示の言語」）。英語になっているときは、メニューの名前は Tools です。
BGM やソースの音が自分に聞こえない。ミュートしたのに聞こえる
モニタリングを確かめてください（9.4）。
チャプターを付けられない
録画フォーマットが「Hybrid MP4 (.mp4)」か「Hybrid MOV (.mov)」か、変えたあと OBS を起動し直したかを確かめます（6.4）。
録画に音が入っていない、一部の音が足りない
「音声」メニューの「録画のトラック割り当てを読む」で、録画に入らないソースが無いかを確かめます（6.9）。
リプレイを保存できない
OBS 本体でリプレイバッファを有効にします（6.6）。
ゲーム切り替えで「ゲーム音 は対象が見つかりません」と読む
8.3 の囲みを読んでください。
Windows やウイルス対策ソフトに起動を止められる
「Windows によって PC が保護されました」なら 3.3 の手順で起動できます。Python で作ったアプリは、ウイルス対策ソフトに誤って検出されることがあります。Windows 11 の「スマート アプリ コントロール」が有効だと、起動できないことがあります。どの場合も、設定を無理に変えずに作者へ知らせてください。
OBS 本体の画面の読み上げがおかしい
OBS 本体の問題で、OBSナビからは直せません。OBSナビで同じ操作ができないか探してみてください。

16. 削除のしかた

OBSナビのフォルダを丸ごと削除します。OBSナビは、自分のフォルダの外（レジストリなど）には何も書きません。

OBSナビで OBS に作ったもの（スクリーンリーダーの声の入力や、BGM のソースなど）は OBS に残ります。要らなければ、削除する前に OBSナビの「ソースを削除」で消すか、OBS 本体で消してください。OBS の WebSocket サーバーを使わなくなったら、「WebSocket サーバー設定」でオフにできます。
