1. このテストで知りたいこと

OBSナビは、スクリーンリーダーで OBS Studio を操作するための道具です。作者の環境（Windows 11、PC-Talker と NVDA、OBS Studio 32.2）では一通り動いていますが、ほかの環境や、ほかの人の使い方ではまだ確かめていません。このテストで知りたいのは次の3つです。

  1. ほかの環境でも、起動・接続・読み上げが正しく働くか
  2. 読み上げの内容が分かりやすいか。足りないところ、多すぎるところはないか
  3. 操作の手順で、分かりにくいところや、つまずくところはないか

うまく使えなかったことも、大切な結果です。遠慮なく知らせてください。

2. テストの前に（大切なお願い）

2.1 OBS の設定を書き出しておく

OBSナビは、シーン・ソース・フィルターを作ったり削除したりできます。削除は元に戻せないので、テストの前に OBS の設定を書き出しておいてください。

  1. OBS の「シーンコレクション」メニュー（Alt+S）の「シーンコレクションをエクスポート」で、ファイルに保存します。
  2. 「プロファイル」メニュー（Alt+P）の「プロファイルをエクスポート」で、フォルダに保存します。

戻すときは、同じメニューの「シーンコレクションをインポート」「プロファイルをインポート」を使います。

普段の設定に触れたくないときは、「シーンコレクション」メニューの「新規...」でテスト用のシーンコレクションを作り、そこで試してください。

2.2 配信のテストについて

OBSナビは配信を開始できます。配信のテストは必須ではありません。試すときは、視聴者に見られても困らない状態で行ってください（YouTube の限定公開や、配信のタイトルを「テスト」にするなど）。

録画は配信先に何も送らないので、安心して試せます。録画したファイルは OBS の録画先のフォルダに残るので、要らなければ削除してください。

2.3 OBSナビが OBS に足すもの

次の操作をすると、OBSナビは OBS の今のシーンに入力やソースを足したり、ソースの設定を変えたりします。

  • スクリーンリーダーの声の入力を作る（F8・F9 を初めて押したとき。作った入力は最初はミュートです）
  • BGM のソースを作る（Ctrl+B を初めて押したとき）
  • ゲーム切り替え（ゲームキャプチャなどの対象のウィンドウを変えます）
  • 録画の音声トラック（「録画のトラック設定」と、ソースの設定の「録画のトラック」を使ったときだけ。OBS の録画の設定と、ソースごとのトラックの設定を書き換えます）

要らなくなったら、OBSナビの「ソースを削除」か OBS 本体で消せます。

3. 準備

マニュアルの「3. 準備と起動」のとおりに準備してください。OBS の WebSocket サーバーを有効にしてから OBSナビ.exe を起動し、「OBSに接続しました」と読めば準備完了です。

ここでつまずいたら、それ自体が大切な結果です。どこで、何と読まれたかを知らせてください。

4. 確かめてほしいこと

項目には番号を付けてあります。知らせるときに「4.1 の3番」のように番号で書いてもらえると助かります。全部でなくてかまいません。

4.1 まずお願いしたいこと

11項目あります。

  1. 起動したとき、「OBSナビ バージョン 0.19.0 の状態」が最後まで読まれるか。続けて「OBSに接続しました」と状態が読まれるか
  2. Tab キーで6つの欄（状態、配信・録画、シーン一覧、ソース一覧、音声入力一覧、フィルター一覧）を回ったとき、欄の名前と、選んでいる項目が読まれるか
  3. Alt キーか F10 でメニューバーを開き、左右矢印でメニューを、上下矢印で項目を移ったとき、項目の名前とキーが読まれるか
  4. リストでアプリケーションキーを押すと操作の一覧が出るか。アプリケーションキーの無いキーボードでは、Shift+F10 で出るか
  5. F1 のキー操作の一覧が、上下矢印で1行ずつ読めるか
  6. シーン一覧の Enter でシーンが切り替わり、「シーン …」と読むか
  7. ソース一覧の Enter で、表示と非表示が切り替わるか
  8. 音声入力一覧の Enter でミュートが切り替わるか。左右キーで音量が変わり、その値を読むか
  9. F5 で状態を、F6 でレベルを読むか
  10. 録画の開始（Ctrl+R）と停止（Ctrl+Shift+R）。止めたときにファイル名を読むか
  11. 「ヘルプ」メニューの「OBSナビについて」で、版と、AI を使って作ったことと、ライセンスのことを読むか

4.2 できればお願いしたいこと

7項目あります。

  1. どこにいても効くキー。ほかのアプリ（メモ帳やゲームなど）を使っている間に、Ctrl+Alt+F5（状態）や Ctrl+Alt+F6（レベル）が効くか
  2. 起動したときに「次のグローバルホットキーは登録できませんでした」と読まれたら、そのキーを知らせてください。お使いのスクリーンリーダーやほかのアプリが、同じキーを使っている可能性があります
  3. スクリーンリーダーやゲームが、OBSナビのキーを先に使ってしまい、効かないことがないか。特に Ctrl+Shift+S、Ctrl+Shift+R、Ctrl+Alt+Shift+F6 から F9、ソース一覧での Alt+上下矢印
  4. ソース一覧で Alt+上下矢印で重なり順を変えたあと、矢印より先に Alt キーを離しても、メニューバーが開かないか
  5. 並び順を変える画面（「シーン一覧の並び順」など）の読み上げが分かりやすいか
  6. ソースの設定、フィルターの追加と設定、カメラの確認、BGM、ゲーム切り替え、映像切り替えのうち、普段使うもの
  7. スクリーンリーダーの声を配信に乗せる機能（PC-Talker は F9。NVDA は準備が要ります。マニュアルの 9.5）。オンとオフのそれぞれで録画して、声が入っているか・入っていないかを確かめてください
  8. 録画の音声トラック（マニュアルの 6.9）。おすすめの割り当てにして録画し、編集ソフトなどでトラックが4本に分かれているか。「録画のトラック割り当てを読む」の読み上げが分かりやすいか

4.3 配信を試せる方へ

3項目あります。

  1. 配信の開始（Ctrl+S）と停止（Ctrl+Shift+S）。確認の画面で「はい」を選べるか
  2. どこにいても効く配信のキー（Ctrl+Alt+Shift+F6 で開始、F7 で停止、どちらも2回続けて押す）。1回目の案内「もう一度押すと配信を開始します」の長さと、8秒の猶予が、お使いの読み上げの速さで足りるか
  3. 配信中の無音や音割れの警告が、うるさすぎないか、足りないか

4.4 自由に使ってみてください

普段の配信や録画の流れで使ってみて、分かりにくかったこと、欲しい機能、読み上げが多すぎる・少なすぎると感じたことを知らせてください。

5. 知らせ方

不具合や気づいたことは、作者（Takahashi）へ知らせてください。次の内容があると、原因を探しやすくなります。

  • OBSナビの版（この配布物は 0.19.0。「ヘルプ」メニューの「OBSナビについて」でも読めます）
  • Windows の版（10 か 11）
  • スクリーンリーダーの名前と版
  • OBS Studio の版（「OBSナビについて」で、接続中の OBS の版も読みます）
  • 何をしたか（押したキーや選んだメニューを順に）
  • 何と読まれたか（聞こえたままで結構です。エラーの文があれば、その文をそのまま）
  • どうなると思っていたか
  • 毎回起きるか、ときどきか

次のひな形をコピーして使えます。8行です。

【OBSナビの版】0.19.0
【Windows】
【スクリーンリーダー】
【OBS Studio の版】
【したこと】
【読まれた内容】
【思っていた動き】
【毎回起きるか】

設定ファイル（OBSナビ.exe と同じフォルダの obs_navi_config.json）を一緒に送ってもらうと、原因が分かることがあります。自分で書き込まない限り、このファイルに OBS のパスワードは入っていません。

6. 分かっている問題

次のことは作者も分かっているので、知らせなくて大丈夫です。6項目あります。

  • 「ゲーム音」という名前のソースが無いと、ゲーム切り替えで「ゲーム音 は対象が見つかりません。ゲームを起動してから…」と読みます。ソースが無いことが原因なのに、ゲームの起動を促してしまいます（対処はマニュアルの 8.3）
  • 「配信・録画」のリストの「配信を開始」で Enter を押しっぱなしにすると、確認の画面が「いいえ」で閉じます（配信は始まりません）
  • 映像フィルター（クロマキーなど）は追加できません
  • シーンの並び順は、OBSナビの中だけで変わります。OBS 本体の並びは変わりません
  • NVDA の声を配信に乗せるには、VB-CABLE の準備が要ります
  • OBS 本体の画面の読み上げの問題は、OBSナビからは直せません
