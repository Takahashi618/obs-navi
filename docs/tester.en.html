OBS Navi 0.20.1 Testing Guide

Author: Takahashi. This is the English edition of the testing guide.

Thank you for helping test OBS Navi. This document covers what to do before testing, what to check, and how to report. How to use OBS Navi is in the manual in the same folder (Manual (English).html or Manual (English).txt).

1. What this test is for

OBS Navi is a tool for operating OBS Studio with a screen reader. It works in the author's environment (Windows 11, NVDA and PC-Talker, OBS Studio 32.2), but it has not yet been checked in other environments or by other people. This test is to find out three things:

  1. Whether starting, connecting, and speech work correctly in other environments
  2. Whether what is spoken is easy to understand, and whether anything is missing or too much
  3. Whether any steps are confusing or hard to get through

Things you could not get to work are important results too. Please feel free to report them. This English edition is especially interested in how the English display and speech sound with your screen reader.

2. Before testing (important)

2.1 Export your OBS settings

OBS Navi can create and delete scenes, sources, and filters. Deletion cannot be undone, so export your OBS settings before testing.

  1. In OBS, use Scene Collection menu (Alt+S), Export, to save the scene collection to a file.
  2. Use Profile menu (Alt+P), Export, to save the profile to a folder.

To restore, use Import in the same menus.

If you do not want to touch your usual setup, create a scene collection for testing with Scene Collection, New, and test there.

2.2 About testing streaming

OBS Navi can start a stream. Testing streaming is optional. If you try it, do so in a way that is fine if viewers see it (for example, an unlisted YouTube stream, or a stream titled "Test").

Recording sends nothing anywhere, so you can try it safely. Recorded files stay in the OBS recording folder; delete them if you do not need them.

2.3 What OBS Navi adds to OBS

The following actions make OBS Navi add inputs or sources to the current OBS scene, or change source settings.

  • Creating a screen reader voice input (the first time you press F8 or F9; the new input starts muted)
  • Creating the BGM source (the first time you press Ctrl+B)
  • Game switch (changes the target window of game capture and similar sources)
  • Recording audio tracks (only when you use Recording track settings or the recording track rows in source settings; changes the OBS recording settings and the per-source track settings)

When you no longer need them, delete them with Delete source in OBS Navi or in OBS itself.

3. Setup

Follow "3. Setup and starting" in the Manual. Enable the OBS WebSocket server, then start OBS Navi. When it reads "Connected to OBS", you are ready.

If you get stuck here, that in itself is an important result. Please tell us where, and what was read.

4. What to check

Each item is numbered. When reporting, it helps if you write the number, such as "4.1 item 3". You do not have to do all of them.

4.1 Please check these first

There are 12 items.

  1. At startup, whether "OBS Navi version 0.20.1 status" is read to the end, followed by "Connected to OBS" and the status
  2. Whether OBS Navi started in English (it follows the Windows display language). Whether choosing 表示の言語 (Language) in the Tools menu lets you switch between English and Japanese, and whether the restart works
  3. When you move through the 6 fields with Tab (status, stream and record, scene list, source list, audio input list, filter list), whether the field name and the selected item are read
  4. When you open the menu bar with Alt or F10 and move between menus with Left and Right Arrow and between items with Up and Down Arrow, whether item names and keys are read
  5. Whether the Applications key in a list shows the list of actions. On keyboards without an Applications key, whether Shift+F10 shows it
  6. Whether the F1 key list can be read one line at a time with Up and Down Arrow
  7. Whether Enter in the scene list switches scenes and reads "Scene …"
  8. Whether Enter in the source list shows and hides the source
  9. Whether Enter in the audio input list toggles mute, and whether Left and Right Arrow change the volume and read the value
  10. Whether F5 reads the status and F6 reads the levels
  11. Starting (Ctrl+R) and stopping (Ctrl+Shift+R) recording, and whether the file name is read when stopping
  12. Whether About OBS Navi in the Help menu reads the version, that it was made with AI, and the license

4.2 Please check these if you can

There are 8 items.

  1. Keys that work anywhere: while using another app (Notepad, a game, and so on), whether Ctrl+Alt+F5 (status) and Ctrl+Alt+F6 (levels) work
  2. If "The following global hotkeys could not be registered" is read at startup, please tell us which keys. Your screen reader or another app may be using the same keys
  3. Whether your screen reader or a game takes any OBS Navi keys first so they do not work. Especially Ctrl+Shift+S, Ctrl+Shift+R, Ctrl+Alt+Shift+F6 to F9, and Alt+Up and Down Arrow in the source list
  4. After changing the stacking order with Alt+Up and Down Arrow in the source list, whether the menu bar stays closed even if you release Alt before the arrow key
  5. Whether the order dialogs (such as Scene list order) are easy to understand by speech
  6. Whichever you normally use of: source settings, adding and configuring filters, checking cameras, BGM, game switch, and video switch
  7. Sending screen reader voices to the stream (NVDA needs setup; see 9.5 in the Manual). Record with it on and with it off, and check whether the voice is or is not in the recording
  8. Recording audio tracks (6.9 in the Manual). Use the recommended assignment, record, and check in an editing program whether the tracks are split into 4. Whether Read recording track assignment is easy to understand

4.3 If you can test streaming

There are 3 items.

  1. Starting (Ctrl+S) and stopping (Ctrl+Shift+S) streaming. Whether you can choose Yes in the confirmation
  2. The streaming keys that work anywhere (Ctrl+Alt+Shift+F6 to start and F7 to stop, both pressed twice in a row). Whether the length of the first message, "Press again to start streaming", and the 8-second window are enough at your speech rate
  3. Whether the silence and clipping warnings during a stream are too frequent or not frequent enough

4.4 Use it freely

Try it in your usual streaming and recording, and tell us what was confusing, features you would like, and where speech felt like too much or too little.

5. How to report

Please report problems and anything you notice to the author (Takahashi). The following makes it easier to find the cause.

  • The OBS Navi version (this package is 0.20.1; About OBS Navi in the Help menu also reads it)
  • The Windows version (10 or 11) and its display language
  • The name and version of your screen reader
  • The OBS Studio version (About OBS Navi also reads the version of the connected OBS)
  • What you did (the keys you pressed and menus you chose, in order)
  • What was read (as you heard it is fine; if there was an error message, the exact message)
  • What you expected to happen
  • Whether it happens every time or only sometimes

You can copy and use the template below. It has 8 lines.

OBS Navi version: 0.20.1
Windows and display language:
Screen reader:
OBS Studio version:
What I did:
What was read:
What I expected:
Every time or sometimes:

Sending the settings file (obs_navi_config.json in the same folder as OBSNavi.exe) along with your report can help find the cause. Unless you wrote it there yourself, this file does not contain your OBS password.

6. Known issues

The author already knows about the following, so there is no need to report them. There are 6 items.

  • If there is no source named "Game Audio", game switch reads "No target found for Game Audio. Start the game, then…". The cause is the missing source, but it suggests starting the game (see 8.3 in the Manual for what to do)
  • If you hold down Enter on Start streaming in the Stream and record list, the confirmation closes with No (the stream does not start)
  • Video filters (such as chroma key) cannot be added
  • The scene order changes only inside OBS Navi. The order in OBS itself does not change
  • Sending the NVDA voice to the stream needs VB-CABLE to be set up
  • Problems with how the OBS window itself is read cannot be fixed from OBS Navi
