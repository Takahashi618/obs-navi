1. Introduction

Many parts of the OBS Studio window are hard or impossible to read and operate with a screen reader. OBS Navi operates OBS from its own window, which is designed to work well with speech.

It uses WebSocket, which comes built into OBS Studio. Keep OBS running and use OBS Navi alongside it. OBS Navi also announces changes made in OBS itself (for example, when streaming starts or the scene changes).

What it can do

  • Start and stop streaming and recording, pause recording, add chapters (markers), save replays, and use the virtual camera
  • Read the status (whether you are streaming or recording, and the current scene)
  • Switch, create, configure, and delete scenes
  • Show and hide sources; create, configure, and delete them; change their stacking order
  • Game switch (point both the game video and the game audio to another game at once), video switch, and BGM playback
  • Mute audio, change the volume (read in decibels), read levels (how loud the sound is right now), and set monitoring (whether you hear it yourself)
  • Add, configure, and delete audio filters (such as noise suppression)
  • Check whether cameras are running, and enable or disable them
  • Send screen reader voices to the stream or keep them out of it
  • Warn about silence and clipping while streaming or recording, and about low disk space while recording
  • Keys that work even while you are in a game
  • Show everything in English or Japanese (chosen automatically from the Windows display language, and changeable from the menu)

What it cannot do

  • Install OBS or set up where you stream (Twitch, YouTube, and so on). Enter your stream key and similar settings in OBS itself
  • Create a YouTube broadcast. Use Manage Broadcast in OBS itself
  • Add video filters (such as chroma key). You can check, turn on or off, and delete video filters that already exist
  • Change the scene order in OBS itself. You can change the order inside OBS Navi
  • Choose where monitoring is heard (which headphones). Set that in OBS itself

Made with AI

The program and this document were written with AI (Anthropic's Claude). The author decides what to build, how it should work, and whether it is easy to use with speech. The author uses it with a screen reader and has fixed it while checking. Its behavior is also checked with automated tests.

About OBS Navi in the Help menu reads this out as well.

Display language

OBS Navi shows its window and speaks in English or Japanese. The first time, it follows the Windows display language: Japanese if Windows is in Japanese, otherwise English.

To change it, choose 表示の言語 (Language) in the Tools menu. This item is written in both Japanese and English so you can find it in either language. Choose one of Automatic, Japanese, or English. OBS Navi then asks whether to restart now; choose Yes to restart in the new language. If you choose No, the new language is used the next time you start OBS Navi.

Names you create in OBS (scenes and sources) are not translated. The default source names that OBS Navi suggests (such as Game Capture and BGM Music) are chosen in the language in use when the settings file is first created.

2. Requirements

  • Windows 10 or Windows 11 (64-bit). Developed and tested on Windows 11
  • OBS Studio 28 or later (the versions with WebSocket built in). Developed and tested with OBS Studio 32.2. Some features, such as chapters, do not work in older versions, so use a version that is as new as possible
  • A screen reader: NVDA or PC-Talker
  • No installation is needed, and no administrator rights are needed

3. Setup and starting

3.1 Enable the WebSocket server in OBS

OBS Navi connects to the WebSocket server in OBS. Do the following once, in OBS.

  1. Start OBS Studio.
  2. Press Alt+T to open the Tools menu, choose WebSocket Server Settings, and press Enter.
  3. Check the Enable WebSocket server check box.
  4. Make sure Enable Authentication is checked. If it is not, check it.
  5. If Server Password is empty, press Generate Password.
  6. Press OK to close.

You do not need to copy the password. OBS Navi reads the password and port from the OBS settings file by itself. If authentication is off, OBS Navi does not connect (it never connects without a password).

If the OBS settings window is hard to use with speech

You can also edit the OBS settings file directly.

  1. Start OBS once, then exit it (the settings file is created the first time OBS starts).
  2. Open this file in Notepad: %APPDATA%\obs-studio\plugin_config\obs-websocket\config.json
  3. Change false to true in "server_enabled": false and save the file. This is the only change needed.
  4. Start OBS.

3.2 Place OBS Navi

  1. Select the zip file, press the Applications key, and choose Extract All.
  2. Put the extracted folder somewhere you can write to, such as Documents.

Do not put it inside Program Files or similar places. OBS Navi creates its settings file (obs_navi_config.json) in its own folder. In a place where it cannot write, settings are not saved.

All file and folder names in the package use only English letters, so they are not garbled. The program is OBSNavi.exe, and this manual is "Manual (English)". English documents end in (English), and Japanese documents end in (Japanese).

Before extracting, if you open the zip file's Properties (Alt+Enter) and check Unblock on the General tab, the Windows warning in the next section will not appear.

3.3 Start

  1. Start OBS Studio first.
  2. Start OBSNavi.exe in the OBS Navi folder.
  3. First it reads "OBS Navi version 0.20.1 status". This is the version of OBS Navi you started.
  4. If it then reads something like "Connected to OBS. Not streaming, Not recording, Current scene …", you are ready.

If a "Windows protected your PC" screen appears, press Tab to move to More info and press Enter, then press Tab to move to the Run anyway button and press Enter. This appears because the app has no digital signature; it does not mean anything is wrong with this package.

If you start OBS later, choose Reconnect to OBS in the Tools menu. If OBS exits first, OBS Navi reads "OBS has exited. Start OBS, then reconnect".

3.4 Exit

Press Alt+F4, or choose Exit in the Stream and Record menu. No confirmation appears.

Escape does not exit. Escape closes settings dialogs, so OBS Navi is designed not to exit when you only meant to close a dialog.

Exiting OBS Navi does not stop OBS, streaming, or recording.

4. The window

The OBS Navi window has 6 fields. Tab moves through them from top to bottom (Shift+Tab moves backward). When OBS Navi starts, you are in the first field, the status.

  1. Status (a read-only field). Its name is "OBS Navi version 0.20.1 status". It holds the streaming and recording state and the current scene, or the reason if the connection failed.
  2. Stream and record (a list with 4 items): Start streaming, Stop streaming, Start recording, and Stop recording. Choose with Up and Down Arrow and press Enter to run. Each item includes its key (for example, "Start streaming Ctrl+S").
  3. Scene list. Enter switches to the selected scene. Selecting alone does not switch.
  4. Source list. The sources in the scene selected in the scene list. Each row reads the name and whether it is shown, such as "Game Capture shown". Enter toggles between shown and hidden. If you select another scene in the scene list, you can check its contents without changing what is on air.
  5. Audio input list. Sources that have audio. Each row reads the name, the mute state, and the volume, such as "Mic on plus 5 decibels" or "BGM muted 0 decibels". Enter toggles mute, and Left and Right Arrow change the volume.
  6. Filter list. The filters of the source you selected last (in the source list or the audio input list). Rows read like "Noise Suppression on". Enter turns a filter on or off.

5. Basic operation

5.1 Lists and Enter

In every list, choose with Up and Down Arrow and press Enter to run. The same actions are also in the menu bar, so you can find them without remembering keys.

5.2 The Applications key menu

Press the Applications key in a list to show the actions available for that list. On keyboards without an Applications key, Shift+F10 does the same. Right after it opens, no item is selected, so press Down Arrow first, then press Enter to run. The first item is always the settings.

Items that cannot be used right now are kept in place (they are read as unavailable). The items for each list are:

  • In the scene list: Scene settings, Create scene, Delete scene, Scene list order (4 items)
  • In the source list: Source settings, Add filter, Create source, Delete source, Bring source forward (stacking order), Send source backward (stacking order), Source list order (7 items)
  • In the audio input list: Source settings, Add filter, Enter volume as a number, Delete source, Level readout order, Read recording track assignment (6 items)
  • In the filter list: Filter settings, Add filter, Delete filter (3 items)

5.3 The menu bar

Press Alt or F10 to open the menu bar. Left and Right Arrow choose a menu, Up and Down Arrow choose an item, and Enter runs it. If an item has a key, it is read after the item name. There are 8 menus, grouped by what they work on: Stream and Record, Scenes, Sources, Filters, Camera, Audio, Tools, and Help. All items are listed in chapter 13.

5.4 Settings dialogs

Source, filter, and scene settings all use the same kind of dialog.

  • You start in the Settings list. Each row has the form "item name, current value".
  • Press Enter to change a value. On or off items switch right away; items with choices show a list; number and text items show an input box.
  • Changes take effect in OBS immediately. There is no Save button.
  • Tab moves to the buttons. Source settings have Reload, Open OBS properties, and Close. Filter settings have Reset to defaults, Reload, and Close. Scene settings have Reload and Close.
  • Escape closes the dialog.

For items this app cannot change, use Open OBS properties to open the OBS window and change them there.

5.5 Confirmation dialogs

A Confirm dialog appears before starting or stopping a stream, deleting something, and similar actions. The buttons are Yes and No, and No is selected at first. Enter alone does not run the action; press Tab to move to Yes, then press Enter. This prevents starting a stream or deleting a source by mistake.

6. Streaming and recording

6.1 Start and stop

  • Ctrl+S starts streaming and Ctrl+Shift+S stops it. Both show a confirmation.
  • Ctrl+R starts recording and Ctrl+Shift+R stops it. There is no confirmation.
  • You can also use the Stream and record list in the window or the Stream and Record menu.

Set your streaming service (Twitch, YouTube, and so on) and stream key in OBS itself beforehand.

When streaming or recording starts, OBS Navi reads "Started streaming" or "Started recording". This is read when OBS reports it, so it is read the same way when you operate OBS itself. If you press start while already streaming, it reads "Already streaming" and does nothing.

Starting and stopping are separate keys so that you do not stop a stream when you meant to start one because you were wrong about the current state.

6.2 Stream and record keys for use in games

These four keys work even while you are using a game or another app.

  • Ctrl+Alt+Shift+F6 starts streaming (press twice in a row)
  • Ctrl+Alt+Shift+F7 stops streaming (press twice in a row)
  • Ctrl+Alt+Shift+F8 starts recording
  • Ctrl+Alt+Shift+F9 stops recording

The two streaming keys confirm by being pressed twice instead of showing a dialog. The first press reads "Press again to start streaming"; pressing again within 8 seconds runs it and reads "Start streaming, confirmed". Pressing another key in between cancels it. Holding the key down does not count as two presses. No dialog is shown so that you are not switched from the game to OBS Navi.

6.3 Pausing recording

Ctrl+P (the key that works anywhere is Ctrl+Alt+Shift+F5) pauses and resumes recording. The F5 status readout says "Recording paused" so you can tell. If recording stays paused, you are reminded every 5 minutes (the interval can be changed in the settings file).

6.4 Chapters

While recording, press Ctrl+Alt+Shift+F12 to add a chapter (a marker for finding the spot later) at that point. Chapters are named with a number and the time in the recording, like "01 00:12:34".

Chapters can be added only when the recording format is Hybrid MP4 or Hybrid MOV. In OBS, go to Settings, Output, Recording Format, and choose "Hybrid MP4 (.mp4)" or "Hybrid MOV (.mov)". After changing it, you need to restart OBS.

To find out whether chapters can be used now, choose Check recording settings in the Stream and Record menu. It reads one of "Chapters can be used", "Chapters can be used after restarting OBS", or "Chapters cannot be used with this format".

6.5 Recording files and checking settings

  • When you stop recording, it reads the file name: "Stopped recording. File …".
  • Open last recording in the Stream and Record menu opens File Explorer with that file selected. If you have not recorded since OBS Navi started, it opens the recording folder.
  • Check recording settings reads the folder, format, quality, encoder, recorded audio tracks, free space, and whether chapters can be used. It only reads; it does not change settings.

6.6 Saving replays and the virtual camera

Ctrl+Alt+F12 saves a replay (the last few tens of seconds). When saving finishes, it reads "Saved replay. File …".

To use replays, turn on Enable Replay Buffer in OBS, Settings, Output. If the replay buffer is not running, OBS Navi starts it first. A replay cannot be saved right after starting, so wait a few tens of seconds and press the key again.

Ctrl+Alt+F11 turns the virtual camera (which passes the OBS video to other apps) on and off.

6.7 Watching while streaming or recording

While streaming or recording, OBS Navi watches for the following three things and tells you.

  • Silence: if an audio input is silent for 60 seconds in a row, it says something like "Mic has been silent for 60 seconds or more". Screen reader voice inputs are often silent, so they are not reported.
  • Clipping: if the sound reaches minus 0.5 decibels or more, it says something like "Mic is clipping".
  • Free space (recording only): it warns when free space on the recording drive falls below 10 gigabytes, and warns strongly below 2 gigabytes.

All of these can be changed in the settings file (chapter 14).

6.8 Reading status and statistics

F5 (the key that works anywhere is Ctrl+Alt+F5) reads whether you are streaming or recording and the current scene. While streaming or recording, it also reads the elapsed time.

Ctrl+Alt+F10 reads statistics: CPU usage, frame rate, whether frames are being dropped, and free space.

6.9 Recording audio tracks (recording sounds separately)

A recording can keep sound on up to 6 separate tracks. If you put the game audio, the screen reader voice, and the microphone on different tracks, you can adjust each volume later in an editing program. In OBS this is a table of check boxes; OBS Navi lists one track per row, and Enter turns it on or off.

There are two things to decide.

  1. Which tracks are recorded: Recording track settings in the Stream and Record menu. It lists 6 rows like "Record track 1, on". Press Enter to toggle; it reads something like "Set recorded audio to tracks 1 to 4. Takes effect from the next recording".
  2. Which tracks each source sends to: select a source in the audio input list and open its settings (the first item of the Applications key menu). At the end are "Recording track 1, on" through "Recording track 6". Press Enter to toggle; it reads something like "Sent Mic to track 4. Now tracks 1 and 4". If you send it to a track that is not recorded, it says that too.

The recommended assignment is below. Track 1 has everything and sounds the same as the stream. Tracks 1 to 4 are recorded. You can also hear it with Hear the recommended assignment in Recording track settings.

The table has 3 rows and 2 columns: "Source" and "Tracks".

SourceTracks
Game and music audio1 and 2
Screen reader voice1 and 3
Microphone1 and 4

To check, choose Read recording track assignment in the Audio menu (or in the Applications key menu of the audio input list). It reads which tracks are recorded and where each source goes, and names any source that does not end up in the recording. It only reads; it does not change settings.

  • The recorded tracks cannot be changed while recording. The setting takes effect from the next recording, so stop recording first.
  • If the OBS output mode is Simple and the recording quality is Same as stream, the recording has a single sound track like the stream, and this setting has no effect. OBS Navi tells you when you open it. In OBS, Settings, Output, set the output mode to Advanced, or set the recording quality to something other than Same as stream.
  • The track used for streaming stays as set in OBS (track 1 by default). If track 1 has everything, the stream sounds the same as before.

7. Scenes

  • Switch: select in the scene list and press Enter. When it switches, it reads "Scene …".
  • Create: choose Create scene in the Scenes menu and enter a name. If the name already exists, a different name is used and read out. Creating a scene does not change the current scene (what is on air does not change).
  • Settings: Scene settings lets you change the name, the transition (used only when switching to this scene), and the transition duration. Add a source to this scene places a source from another scene.
  • Delete: Delete scene. The confirmation tells you that sources that exist only in this scene are deleted with it and that this cannot be undone. The last scene cannot be deleted.
  • Order: Scene list order changes the order of the list in OBS Navi. The order in OBS itself does not change.

Adding a source to a scene shares the same source rather than copying it. Changing its settings in one place affects every scene it is in.

8. Sources

8.1 Show and hide

Press Enter in the source list to toggle between shown and hidden.

Hiding a source also removes its sound

In OBS, hiding a source also removes its sound from the stream and the recording. To switch only the picture, use Video switch (8.4) or the stacking order (8.6).

8.2 Create, configure, delete

Choose Create source in the Sources menu, choose a kind, and enter a name. It is created in the scene selected in the scene list.

The settings dialog opens right after creating. First choose the items without which nothing is shown or heard, such as the target game for a game capture or the device for a camera.

The kinds of sources you can create, in the order they appear in the list. The table has 12 rows and 2 columns: "Kind" and "What it is for".

To change settings, select the source in the source list or the audio input list and choose Source settings in the Applications key menu. For sources with audio, the first row of the settings is monitoring (9.4).

To delete, choose Delete source. Deleting a source does not just remove it from this scene; it removes it from all scenes. This cannot be undone. If the source is used for BGM, Game switch, or a screen reader voice, the confirmation says so.

8.3 Game switch

F3 (the key that works anywhere is Ctrl+Alt+F3) shows a list of running game windows. Choose one and press Enter to point both the game video and the game audio to that game.

  • For video, the source named "Game Capture" is used by default. If there is no source with that name, a game capture source is used (if there are two or more, you choose).
  • The audio switched together is the Application Audio source named "Game Audio" by default.

When it reads "No target found for Game Audio"

This is also read when there is no source named "Game Audio" (it goes on to say "Start the game, then press F3 again", but starting the game does not fix it). To switch the game audio too, create an Application Audio source named "Game Audio", or write the name of your source in audio_sources under game_switch in the settings file.

If the source names were created while OBS Navi was in Japanese, the default names are the Japanese ones (ゲームキャプチャ and ゲーム音). The names in the settings file are the ones used.

When called with the key that works anywhere, OBS Navi brings its window to the front before showing the list. If it cannot, it tells you to switch to OBS Navi with Alt+Tab and press F3.

8.4 Video switch

Ctrl+E chooses which video source in the scene on air is brought to the very front. When the capture card's picture (a screen with no signal) covers the game screen, you can switch without removing a source.

It does not hide anything, so the sound is not affected. Note that the capture card's sound keeps going to the stream even when its picture is behind. To stop it, mute it in the audio input list.

8.5 BGM

Ctrl+B (the key that works anywhere is Ctrl+Alt+F7) plays and pauses BGM.

  • The first time, it asks whether to create a source for BGM (named "BGM Music" by default) in the current scene. Choose Yes and a file chooser for the music file appears.
  • If OBS already has a Music or Video File source, that is used (if there are two or more, you choose).
  • If the music file cannot be found, a chooser appears so you can pick it again.

If you cannot hear the BGM yourself, check monitoring (9.4).

8.6 Stacking order and list order

In the source list, Alt+Up Arrow brings the selected source one step forward and Alt+Down Arrow sends it one step back. It reads the new position, such as "Position 2 from the front, of 5". The stacking order is the front-to-back order of the picture and is also changed in OBS itself. It does not affect sound.

Source list order changes only the order of the list in OBS Navi (OBS itself does not change).

In the order dialog, Alt+Up and Down Arrow in the list move the selected row one step at a time. The Move up and Move down buttons do the same. Save confirms, and Cancel discards.

9. Audio

9.1 Mute

Press Enter in the audio input list to toggle mute.

Mute only keeps the sound out of the stream and the recording. A source with monitoring on is still heard by you when muted. Conversely, a source set to Monitor only is not sent to the stream even when unmuted. In both cases, OBS Navi adds a note when it reads the change.

9.2 Volume

  • In the audio input list, Left and Right Arrow change the volume by 1 decibel, and Shift+Left and Right Arrow by 5 decibels.
  • F7 lets you type a number, such as "-10", "5", or "+3.5". Full-width digits and a trailing "dB" are also accepted. The range is minus 100 to plus 26 decibels.
  • The keys that work anywhere are Ctrl+Alt+F1 to lower and Ctrl+Alt+F2 to raise, and Ctrl+Alt+Shift+F1 and F2 to lower and raise in larger steps. The target is the input selected in the audio input list. Ctrl+Alt+F4 moves the target to the next input and reads its name and volume.

Volume is read in decibels ("Mic plus 6 decibels"). It can also handle values above 0 decibels, which the OBS mixer slider cannot reach.

9.3 Reading levels

F6 (the key that works anywhere is Ctrl+Alt+F6) reads how loud each input is right now, one after another. It reads the maximum over the last 3 seconds, so it does not say "silent" just because you pressed during a pause for breath. Muted inputs are read as "muted".

You can change the order with Level readout order in the Audio menu. Inputs not in the order follow at the end in name order. Turning on Do not read muted sources skips muted inputs.

9.4 Monitoring (whether you hear it yourself)

By default in OBS, a source's sound goes to the stream and the recording, but you do not hear it. This is usually why you cannot hear BGM you added.

Change it in the first row of the source settings dialog. There are three choices:

  • Off, sent to the stream but you do not hear it (the OBS default)
  • Monitor only, not sent to the stream
  • Monitor and output, you hear it and it is sent to the stream

Where it is heard (which speakers or headphones) is set with Monitoring Device in OBS, Settings, Audio.

9.5 Sending screen reader voices to the stream

By default, you can send the NVDA voice and the PC-Talker voice to the stream, or keep them out, separately.

  • NVDA voice: F8 (the key that works anywhere is Ctrl+Alt+F8)
  • PC-Talker voice: F9 (the key that works anywhere is Ctrl+Alt+F9). PC-Talker is a Japanese screen reader

Each press switches between sending and not sending (it toggles the mute of that input).

The first time you press it, OBS Navi asks whether to create an input to capture the voice. Choose Yes to create the input in the current scene. The new input starts muted (not sent to the stream); press again to send it. Screen reader voices are only sent when you explicitly choose to, so they do not leak into a stream by accident.

For PC-Talker

Only the PC-Talker voice is captured (using Application Audio). PC-Talker must be running when the input is created.

For NVDA

NVDA has no window to capture from, so its voice is captured through the free virtual audio cable VB-CABLE. Setup is needed; do the following only if you use it.

  1. Install VB-CABLE from https://vb-audio.com/Cable/. After installation, "CABLE Output" appears among the recording devices. The installer window may not be read by your screen reader. In that case, open a Command Prompt as administrator, go to the extracted folder, and run VBCABLE_Setup_x64.exe -i -h to install without the window (the author confirmed this method).
  2. Open the Windows Sound settings (press Windows+R and type mmsys.cpl). On the Recording tab, open the properties of "CABLE Output". On the Listen tab, check Listen to this device and set the playback device to your usual speakers or headphones. Without this, you will no longer hear NVDA yourself.
  3. In NVDA's settings, Audio category, set the output device to "CABLE Input".
  4. Press F8 in OBS Navi to create the input.

To undo this, set NVDA's output device back.

Screen reader voice inputs are often silent, so they are excluded from the silence warning. Their names, keys, and capture methods can be changed in sr_sources in the settings file.

10. Filters

The filter list shows the filters of the source you selected last (in the source list or the audio input list).

  • On or off: press Enter in the filter list. It reads something like "Enabled Noise Suppression".
  • Add: select a source in the source list or the audio input list and choose Add filter in the Applications key menu (it is also in the Filters menu). The list of kinds reads each name and what it is for. Noise Suppression is selected at first.
  • Settings: Filter settings changes values and methods. Reset to defaults returns them to the original values. The name and order do not change.
  • Delete: Delete filter. A confirmation appears.

The kinds of audio filters you can add, in the order they appear in the list. The table has 9 rows and 2 columns: "Kind" and "What it is for".

Kind What it is for
Noise SuppressionReduces constant sounds such as air conditioners and computer fans
Noise GateMutes the sound when it is quiet. Removes noise while you are not talking
CompressorTames loud sounds to even out the volume. Makes your voice easier to hear
LimiterKeeps the sound from going over a set level. Prevents clipping
GainRaises or lowers the volume. Use it when the microphone is too quiet
EqualizerChanges the amount of low, mid, and high frequencies
ExpanderMakes quiet sounds even quieter. Gentler than a noise gate
Upward CompressorLifts quiet sounds. Makes whispers easier to hear
Invert PolarityInverts the sound wave. Use it when two microphones cancel each other out

Video filters cannot be added. If you choose Add filter on a source without audio, OBS Navi reads why.

11. Camera

  • Check cameras: Check cameras in the Camera menu reads, for each camera (video capture device) source, the device name, whether it is running, whether video is coming in, and whether it is shown. It also tells you about devices connected to the computer that OBS is not using.
  • Enable or disable: Enable or disable camera (the key that works anywhere is Ctrl+Alt+Shift+F11) stops or starts the camera. If there are two or more camera sources, you choose. About 2.5 seconds after switching, it checks and reads the actual state, and if the camera could not be stopped, it warns "Could not stop … The camera is still running".

This is different from Toggle virtual camera (Ctrl+Alt+F11). This one is a real camera; the other is the virtual camera that passes the OBS video to other apps.

14. Settings file

Settings are in obs_navi_config.json in the same folder as OBSNavi.exe. It is created the first time OBS Navi starts. Things you change in OBS Navi, such as list orders and the BGM source name, are also saved here.

  • To edit it, exit OBS Navi first, then open it in Notepad or similar. If you edit it while OBS Navi is running, OBS Navi may overwrite it.
  • If the file is broken and cannot be read, OBS Navi starts with the default settings and tells you so. In that case, changes are not saved (so that the broken file is not overwritten).
  • To return to the initial state, exit OBS Navi and delete this file. It is created again the next time OBS Navi starts.
  • The password for connecting to OBS is not stored in this file (it is read from the OBS settings file).

15. Troubleshooting

It reads "Could not connect to OBS. Check that OBS is running"
Check that OBS is running and that the WebSocket server is enabled (3.1). If you started OBS later, choose Reconnect to OBS in the Tools menu.
It reads "Could not get the WebSocket password"
In OBS, WebSocket Server Settings, check Enable Authentication, make sure there is a server password, and close with OK. Then choose Reconnect to OBS.
It reads "Authentication with OBS failed"
This happens, for example, right after the password was regenerated in OBS. Close WebSocket Server Settings in OBS with OK, then choose Reconnect to OBS.
Nothing is spoken
Check that your screen reader is running. OBS Navi finds the running screen reader and speaks through it.
It reads "The following global hotkeys could not be registered" at startup
Another app is using some of the keys that work anywhere. Those keys do not work, but other keys and the menus do. Changing global_hotkey_modifier in the settings file moves them all to another modifier.
Settings are not saved
The folder may not be writable. Move it to Documents or a similar place (3.2).
The window and speech are in Japanese (or English) and I want the other
Choose 表示の言語 (Language) in the Tools menu (Alt+T) and pick the language (see Display language in chapter 1).
I cannot hear BGM or a source myself. I still hear it after muting
Check monitoring (9.4).
Chapters cannot be added
Check that the recording format is "Hybrid MP4 (.mp4)" or "Hybrid MOV (.mov)", and that you restarted OBS after changing it (6.4).
The recording has no sound, or some sounds are missing
Use Read recording track assignment in the Audio menu to check whether some sources are not recorded (6.9).
Replays cannot be saved
Enable the replay buffer in OBS (6.6).
Game switch reads "No target found for Game Audio"
Read the box in 8.3.
Windows or antivirus software blocks it from starting
For "Windows protected your PC", follow the steps in 3.3. Apps made with Python are sometimes falsely detected by antivirus software. If Smart App Control in Windows 11 is on, the app may not start. In any of these cases, please tell the author instead of forcing a change to your settings.
The OBS window itself is read strangely
That is a problem in OBS itself and OBS Navi cannot fix it. See whether the same action can be done in OBS Navi.

16. Uninstalling

Delete the whole OBS Navi folder. OBS Navi writes nothing outside its own folder (nothing in the registry, for example).

Things OBS Navi created in OBS (screen reader voice inputs, the BGM source, and so on) stay in OBS. If you do not need them, delete them with Delete source in OBS Navi before removing it, or delete them in OBS itself. If you no longer use the OBS WebSocket server, you can turn it off in WebSocket Server Settings.
